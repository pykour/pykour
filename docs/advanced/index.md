# Advanced

This section covers advanced features of Pykour that help you build production-ready applications. These features go beyond basic routing and request handling, providing tools for performance optimization, observability, code generation, and more.

## Topics

- [Caching](caching.md) -- Response and data caching with in-memory and Valkey backends
- [OpenAPI](openapi.md) -- Automatic API documentation with Swagger UI and ReDoc
- [Testing](testing.md) -- Test client for ASGI applications with auth helpers
- [Configuration](configuration.md) -- TOML-based configuration with environment variable overrides
- [CLI](cli.md) -- Command-line interface for running, generating, and managing your app
- [Metrics](metrics.md) -- Prometheus-compatible metrics collection and export
- [Health Checks](health-checks.md) -- Health check endpoints for load balancers and orchestrators
- [CRUD Generation](crud.md) -- Automatic CRUD endpoint generation from Table definitions
- [Response Decorators](response-decorators.md) -- Declarative status codes, headers, and conditional responses
